Phase 2 — AI-Assisted Coding

AI-Powered Code Review

Automated code review tools that catch bugs, suggest improvements, and speed up PR feedback

What AI Code Review Does

AI code review tools analyze pull requests automatically and post comments identifying bugs, security issues, performance problems, and style inconsistencies. They read context across multiple files, trace cross-file dependencies, and provide actionable suggestions. Tools like CodeRabbit, GitHub Copilot, and Graphite's AI reviewer have become standard parts of many teams' PR workflows.

Key insight: AI review is a first-pass filter, not a replacement for human review. It catches obvious issues and frees reviewers to focus on logic and design.

Major Tools: CodeRabbit vs GitHub Copilot

CodeRabbit: Specialist in PR review, works on GitHub, GitLab, Azure DevOps, and Bitbucket. Focused, opinionated, provides detailed line-by-line feedback. Great for teams using non-GitHub platforms.

GitHub Copilot: Generalist with code review as one capability. Integrated into GitHub workflow, works natively with pull requests. Added agentic architecture that reads relevant files and traces cross-file dependencies better than earlier versions.

Choose based on your platform: GitHub users have native Copilot, others should use CodeRabbit.

Reviewing Pull Requests

Create a PR as usual. AI bot automatically reviews and posts comments within minutes. Comments include: bug risks, missing edge cases, performance concerns, security vulnerabilities, style issues, and test coverage gaps. Review AI suggestions the same way you'd review human comments—some are actionable, others may be context-dependent or business-specific. You keep final say on all changes.

  • Enable AI review in your repository settings
  • Most tools auto-run on every PR without extra setup
  • Configure which languages and rules to check
  • Exclude certain files (test fixtures, generated code)

Catching Bugs and Vulnerabilities

AI tools detect null pointer exceptions, incorrect error handling, SQL injection risks, hardcoded secrets, race conditions, and logic flaws. They understand common mistake patterns: forgetting null checks, off-by-one errors, uncaught promise rejections, or missing input validation. A strong AI review catches issues that might slip past tired reviewers, especially on Friday afternoons.

Pro tip: Use AI review to enforce security standards automatically (no secrets in code, no unsafe operations) without burdening human reviewers.

Suggesting Improvements

AI proposes refactoring: "This could be a const instead of let," "Extract this repeated logic into a helper," or "Consider using a Set here instead of Array.includes for O(1) lookup." Not all suggestions need accepting—some may conflict with your architecture or conventions. Good AI tools explain the why: "This is more efficient because..." or "This pattern is clearer because..."

Understanding Unfamiliar Codebases

When reviewing code in an unfamiliar library or team module, AI can explain what changed and why. Ask in comments: "@CodeRabbit explain this algorithm" or use the chat feature to understand design decisions. Useful for onboarding or cross-team reviews where you lack domain context.

Best Practices

  • Configure rules for your stack: Different teams need different checks. Disable rules that don't apply
  • Read AI comments in context: A suggestion might seem wrong without understanding the larger pattern
  • Don't blindly accept changes: Understand why AI flagged something before deciding to fix it
  • Use alongside human review: AI catches easy bugs; humans catch logic errors and design issues
  • Track improvement over time: Review AI comments to identify patterns in your code quality
  • Customize severity: Not all warnings are equally important—configure what blocks merges

Common Limitations

AI review can't understand business context ("Is this deliberate duplicate logic?"). It may flag false positives on intentional patterns. It's less effective with complex architectures it wasn't trained on. Always maintain human review for critical paths and business logic.
