Markdown Basics

Essential formatting for communicating with AI tools, specs, and documentation.

Why Markdown Matters

Markdown is the lingua franca of AI development. You use it in prompts, context files, spec documents, and README files. Learning it well means faster, clearer communication with AI tools and your team.

All major AI models (Claude, ChatGPT, Gemini) render markdown in their responses. GitHub, Discord, and most documentation platforms support it. It's lightweight, readable, and universal.

Headers

Use # signs. One # is h1, two is h2, etc. Always add a space after the #.

# Heading 1 ## Heading 2 ### Heading 3 #### Heading 4

Renders as progressively smaller headings. Use this structure to organize your prompts and specs logically.

Emphasis

Bold: Wrap text with **text** or __text__

Italic: Wrap with *text* or _text_

Bold + Italic: ***text***

**This is bold** *This is italic* ***This is bold and italic***

Lists

Unordered lists: Use -, *, or + followed by a space:

- Item one - Item two - Item three

Ordered lists: Use 1., 2., etc:

1. First step 2. Second step 3. Third step

Nested lists: Indent with 2–4 spaces:

- Parent item - Child item - Another child - Next parent

Code

Inline code: Wrap with backticks: `this is code`

Code blocks: Use three backticks on separate lines. Optionally specify the language for syntax highlighting:

```python def hello(): print("Hello, world!") ```

Supported languages: python, javascript, java, go, rust, sql, bash, json, yaml, html, css, etc.

Always use fenced code blocks (triple backticks) in AI prompts, not indented blocks. It's clearer and shows syntax highlighting in the AI's response.

Links

Basic link: [link text](https://example.com)

[Google](https://google.com) [My GitHub](https://github.com/username/repo)

The text in brackets is what displays; the URL in parentheses is the target.

Tables

Markdown tables use pipes | to separate columns and dashes --- for the header row:

| Header 1 | Header 2 | Header 3 | |----------|----------|----------| | Cell 1 | Cell 2 | Cell 3 | | Cell 4 | Cell 5 | Cell 6 |

Alignment: Add colons in the header separator:

| Left | Center | Right | |:-----|:------:|------:| | L | C | R |

Left-aligned (default), center-aligned, and right-aligned columns.

Blockquotes

Use > to start a blockquote:

> This is a quote. > It can span multiple lines. > > And multiple paragraphs.

Useful for showing user input, requirements, or context.

Horizontal Rule

Use ---, ***, or ___ on its own line:

Some text above --- Some text below

Quick Reference for AI Prompts

Structure your AI prompts with markdown:

## Task Write a function that... ## Requirements - Must handle edge cases - Return type should be... - Include docstring ## Context I'm using Python 3.10 with FastAPI. ## Example Input: [example] Output: [expected output] ## Constraints - Don't use external libraries

This structure makes your prompt scannable and helps the AI understand priorities. AI models respond better to structured input.

Pro tip: Save markdown templates for tasks you do repeatedly (code reviews, documentation, system design). Reuse them to save time and ensure consistency.
