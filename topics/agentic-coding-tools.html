Agentic Coding Tools

Explore the landscape of modern AI coding agents—what makes them "agentic," the major platforms, and how to choose the right one for your workflow.

What Makes a Tool "Agentic"?

Simon Willison put it simply: "An agent is an LLM that runs tools in a loop." That's really all it is. The LLM decides what to do, calls a tool (read a file, run a command, edit code), sees the result, and decides the next step. It keeps looping until the task is done or it gets stuck.

At the core, every agentic coding tool is running something like this:

while not done:
    response = llm(conversation + tool_results)
    if response.has_tool_calls:
        tool_results = execute(response.tool_calls)
    else:
        done = True

The differences between tools — Claude Code, Cursor, Aider, etc. — are in which tools they expose (file editing, shell, browser, git), how they manage permissions, and how they present results. But the core loop is the same.

Major Agentic Platforms

Claude Code (Anthropic) — Terminal-native CLI, desktop app, and IDE extension. Supports Claude Opus, Sonnet, and Haiku models. Handles git workflows, reads entire codebases, executes commands with permission gates. Strong at multi-step reasoning and autonomous iteration.

GitHub Copilot (Microsoft/GitHub) — Deeply integrated into VS Code and available as a standalone CLI. Agent mode plans and executes multi-file edits. Copilot CLI adds autopilot mode, fleet mode for parallel tasks, and specialized sub-agents. If your company already pays for GitHub Enterprise, this may be your default.

Cursor — VS Code fork with AI deeply integrated. Agent mode plans and executes multi-file edits. Supports multiple models (Claude, GPT, Gemini). Ideal for IDE-centric workflows.

Windsurf (OpenAI) — Agentic IDE with Cascade engine. Auto-detects and fixes lint errors, integrated terminal, design-to-code. Acquired by OpenAI in 2025.

Google Antigravity — Google's agentic IDE, launched alongside Gemini 3. Features both an editor view and a "manager view" for orchestrating multiple agents in parallel. Free in public preview; supports Gemini models plus Claude and GPT.

Aider — Open-source CLI for git repositories. Excels at multi-file refactoring. Works with Claude, GPT-4o, DeepSeek. Free tool; you pay only for the underlying LLM API calls.

OpenCode — Open-source Go-based terminal agent with 95K+ GitHub stars. Supports 75+ models including local Ollama. No subscription — you pay only for API calls. Good option if you want multi-model freedom or need to run in privacy-sensitive environments.

Cline — Open-source VS Code extension with human-in-the-loop safety. Browser control via computer use. Multi-provider support (Anthropic, OpenAI, Gemini, etc.).

How to Choose

  • Your company already provides one: Use it. If your org pays for GitHub Copilot, Cursor Business, or Anthropic Max, start there. Tool choice matters less than consistent usage, and fighting procurement for a different tool is wasted energy.
  • No company tool / personal projects: Pick one and commit for 1-2 weeks. Claude Code and Cursor are the most popular starting points.
  • Cost-conscious: Aider or OpenCode (open source, pay only for LLM API) or Claude Code (API credits or Max subscription)
  • Multi-model freedom: OpenCode (75+ models), Cline (8+ providers), or Aider
  • UI/design work: Cursor Composer or Windsurf (design-to-code)

Tip: Start with one tool in a test project for 1–2 weeks. Agentic tools have different personalities; picking the wrong one early wastes time. Many developers use multiple tools for different task types.
